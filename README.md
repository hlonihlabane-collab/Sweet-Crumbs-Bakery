#  Sweet Crumbs Bakery

**Freshly Baked Happiness in Every Bite!**

Sweet Crumbs Bakery is a fictional bakery website created as a student web development project. The website allows visitors to learn about the bakery, view the menu, see specials, browse the gallery, make enquiries and find contact information.

## About the Project

The website was developed using HTML5, CSS3, Bootstrap 5 and Bootswatch. Custom CSS was also used to create the bakery's colours, layout and responsive design.

The main aim of the project is to demonstrate the development of a multi-page website with consistent navigation, images, responsive layouts and organised content.

## Website Pages

The website contains the following pages:

* index.html – Home page
* About.html – About Us page
* Menu.html – Bakery menu
* Specials.html – Special offers
* Gallery.html– Bakery image gallery
* Enquiry.html – Enquiry page
* Contact.html – Contact page

The main navigation links are:

```text

About Us
Menu
Specials
Gallery
Enquiry
Contact
```

The navigation is available throughout the website so that visitors can move between the different pages.

On smaller screens, the navigation changes to a hamburger menu to make it easier to use on phones and tablets.

## Responsive Design

The website was designed to work on different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

CSS media queries and Bootstrap responsive features are used to adjust the layout for smaller screens.

## Images

Bakery images are stored in the images folder and are linked to the webpages using relative paths.

Alternative text is included on images where appropriate.
